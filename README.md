# 🏥 Medcare - Premium AI-Powered Healthcare Platform

Medcare is a state-of-the-art, full-stack MERN (MongoDB, Express, React, Node.js) application designed to bridge the gap between patients and healthcare professionals. Featuring a premium design system, AI-ready architecture, and a seamless booking experience.

## ✨ Key Features
- **Modern Premium UI**: Glassmorphism, dynamic animations, and a sleek dark/light mode aesthetic.
- **Smart Search**: Find doctors by name, specialization, or location with real-time suggestions.
- **Doctor & Patient Dashboards**: Personalized experiences for both roles with appointment tracking and profile management.
- **Secure Payments**: Integrated Stripe checkout for consultation bookings.
- **AI-Powered**: Architecture ready for AI diagnostic integrations.
- **Deployment Ready**: Fully optimized for Render (Backend) and Vercel (Frontend).

## 🚀 Tech Stack
- **Frontend**: React.js, TailwindCSS, React-Icons, Swiper.js.
- **Backend**: Node.js, Express.js.
- **Database**: MongoDB Atlas with Mongoose.
- **Authentication**: JWT (JSON Web Tokens) with Secure HTTP-only cookies.
- **Payments**: Stripe API.

## 📂 Project Structure
```text
Medcare/
├── frontend/     # React Application
└── backend/      # Node.js API
```

## 🛠️ Getting Started
1. **Clone the repository**:
   ```bash
   git clone https://github.com/Codecrafter2807/Medcare.git
   ```
2. **Setup Backend**:
   - Go to `backend/` and run `npm install`.
   - Create a `.env` file and add your `MONGO_URL`, `JWT_SECRET_KEY`, `STRIPE_SECRET_KEY`, and `CLIENT_SITE_URL`.
3. **Setup Frontend**:
   - Go to `frontend/` and run `npm install`.
   - Run `npm start`.
