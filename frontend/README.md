# 💻 Medcare Frontend

The frontend of Medcare is built with **React.js** and styled using a custom-built premium design system based on **TailwindCSS**.

## 🎨 Design Philosophy
- **Rich Aesthetics**: High-quality visuals, curated color palettes, and modern typography.
- **Micro-interactions**: Subtle hover effects and transitions for a premium feel.
- **Responsiveness**: Fully optimized for mobile, tablet, and desktop.

## 🛠️ Installation
```bash
npm install
```

## 🚀 Available Scripts
- `npm start`: Runs the app in development mode at [http://localhost:3000](http://localhost:3000).
- `npm run build`: Builds the app for production in the `build` folder.

## 🔑 Environment Variables
Create a `.env` file in the root of the `frontend` folder:
```text
REACT_APP_BASE_URL=https://your-api-url.com/api/v1
```
